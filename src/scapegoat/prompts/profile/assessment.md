# 心理测评式建档（对本人施测）

以心理测评的交互形式为**作答者本人**建立或更新画像。与 `init.md`（访谈知情人、谈论第三者）互补：这里画像对象就是屏幕前作答的人。写入遵守 `merge_rules.md`（必须先读）。

## 施测原则

1. **行为采样优于自陈**。人对自己的概括不可靠，对具体事件的复述相对可靠。所以题目问"上一次发生 X 你做了什么"，不问"你是不是一个 X 的人"。
2. **情境判断优于态度表态**。给具体两难情境让作答者选择并说理由，选项设计成各维度的分化器（不同心理结构的人会选不同项）。
3. **间接测防御**。防御机制、优先级这类维度不能明问（明问必然触发防御本身）。用投射式与冲突式题目：让他评价一个虚构人物的行为、解释一次自己的失败、在两个都有代价的选项间强制二选一。
4. **一次一题，追问到具体**。作答抽象时追问"最近一次具体是什么情况"。每题拿到**可引用的具体作答**才进入下一题。
5. **不给测评式反馈**。过程中不打分、不解读、不评价作答"好坏"，保持中性推进，避免作答者迎合。

## 题目结构（约 25–35 题，按维度组织）

每个维度 2–4 题，混合三种题型——SJ（情境判断：给情境+选项+说理由）、BS（行为采样：复述真实事件）、FC（强制二选一权衡）。逐维度示例方向：

| 维度 | 题型侧重 | 示例题干方向 |
|---|---|---|
| formation | BS | 讲一件小时候印象最深的被对待方式；你从家里学到的最重要的"生存规则"是什么 |
| worldview | SJ+FC | 某人靠关系升职你怎么解释；"人会变"还是"人不会变"，用你认识的人举例 |
| personality | BS | 独处的一个周末你实际怎么过的；上次别人向你倾诉你怎么回应的 |
| cognition | SJ | 接到一个陌生问题你的第一步实际是什么（要最近真实一例）；上次改变观点是被什么说服的 |
| affect | BS | 完成一件大事之后的当晚你在做什么、什么感受；说一次"表面平静内心不是"的时刻 |
| drives_fears | FC+BS | "重要机会但可能出丑" vs "安全但平淡"选哪个（要真实先例）；最近一次过度反应是被什么触发的 |
| defenses | SJ（投射） | 虚构人物 A 被当众指出错误后转移话题——你怎么看 A；你上次被批评，当时第一反应和事后想法各是什么 |
| narratives | BS | 你会怎么向陌生人讲你的人生转折点；你反复对别人讲的道理是哪一条 |
| situational | SJ | 同一个请求来自上级/下属/家人，你的回应有何不同（各要一例） |
| execution | BS | 上次布置/接手任务的完整过程；上次返工你把原因归到哪里 |
| priorities | FC | 承诺 vs 当下方便、面子 vs 关系、安全 vs 利益——每对给一个具体两难，强制选择并要真实先例 |

题目就地生成，贴合作答者的语境（职业、已答内容），不逐字照搬示例。**自适应**：某维度前两题已给出清晰分化信号则跳过后续题；信号矛盾则加追问题。

## 评分与转档

测评结束后，逐维度做三件事：

1. **证据登记**：每条作答记为证据（题号 + 作答要点），与语料证据同等地位。
2. **一致性核查**：作答之间、作答与已有画像之间的矛盾，优先解释为"自陈叙事 vs 实际优先级的分裂"——这本身是 narratives/defenses 的高价值证据，不要抹平。
3. **生成/合并规则**：压缩成 `情境 → 行为` 预测规则写入画像，全程执行 merge_rules.md（自陈来源的规则默认置信度低于行为语料，需标注 `来源: 测评自陈`）。

写入后：更新来源记录行 → 运行 `scapegoat profile budget <subject_id> --strict` → 汇报更新与预算结果，提示需要时重新 freeze。
