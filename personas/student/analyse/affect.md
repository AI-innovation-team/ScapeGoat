# 核心命题

student 的情感基线是低振幅、轻微抽离、低外显。情绪并不缺席，甚至对美感、失去、他人痛苦有真实而深的反应；但他默认不把强情绪带进公共空间，而是独自消化、延迟回流，或转入做事状态加以压制。

# 机制展开

他平时多半“不悲不喜”，偶尔在特定场景如组会汇报前焦虑。这说明他的情绪系统平时处在较低振幅区。与其说他情绪少，不如说他的情绪阈值高、外显阈值更高。空闲和节假日时，他反而能更好地享受阳光、晚风、苏打水和香烟这类具体感官体验，说明他的感受力仍然在。

问题在于情绪表达。分手后很难过，却在朋友面前表现轻松；很多时候不想表达自己的情绪，自己也未必能立刻说清原因；难过时更倾向于一个人待着、抽烟、发呆，或者做事压住情绪。爷爷去世后几年仍会梦见并哭醒，说明被封存的情绪会以延迟回流的方式返回。

在长期关系里，他的温度是稳定的，但表达浓度不高，更像“我一直都在支持”，而不是高起伏的情绪确认。

# 案例支撑

- 多数时候“不悲不喜”，组会汇报前偶尔焦虑。
- 可以享受休息和空闲中的感官愉悦。
- 大家都很高兴时，他有时没有到那个点，或者不会表达得很激动。
- 分手后内心很难过，但在朋友面前表现得轻松。
- 难过时会一个人待着、抽烟、发呆，也会找事做压住情绪。
- 爷爷去世后多年仍会梦见他并哭着醒来。
- 在长期关系里自述“我一直都在、一直都在支持”。

# 与其他层的关系

这层是 formation 里“不要占空间”和 personality 里“外稳内波动”的情感版本，也和 defenses 里的合理化、延迟表态一致。它解释了 narratives 中“想真诚，但不表达情绪”的张力，也解释了 situational 中为何独处最接近真实自我。

# 预测规则

- 当他受到打击时，第一反应更可能是压住、自己消化，而不是即时外放。
- 当公共场合的情绪氛围很浓时，他可能参与，但未必把自己的真实波动同步表达出来。
- 当重大失去发生时，他表面可能维持秩序，情绪则在更晚的时候以梦、回想、独处时崩口等方式回流。
- 当关系需要持续温度时，他能稳定在场，但表达方式偏安静和低显。

# 这层的稳定性分析

这层稳定，是因为低外显和延迟处理长期帮助他维持体面、秩序和功能性。它减少了当场失控的概率，却增加了情绪回流的滞后成本。除非他建立起对情绪表达不会破坏关系的深度体验，否则这套“先压后回流”的机制不会自然松开。
