# 核心命题

student 的情境规则是按信任、价值观和风险感分层开放自己。面对权威，他优先交付、保持礼貌和距离；面对依赖他的人，他会多承担并暗中付出；面对值得尊重的人，他才会真正交心；面对不认同的人，他不会硬碰，但会迅速撤回深度投入。其行为表面变化不一定大，心理开合却很明显。

# 机制展开

他在人际中不是平均开放的。对上级和权威，他默认“把交代的事做好，不惹麻烦，没有必要多暴露”，说明功能交付优先于自我呈现。对弱一些、依赖他的人，他耐心、替对方想很多，而且别人通常并不知道他实际付出了多少，这是一种隐性承担模式。

同辈关系里，尊重感是开门条件。对尊重的人可以交心，对不尊重的人则不投入。这种“不尊重”主要指价值观差、不真诚、工具化别人、自我膨胀。对家人，他反而更克制，说明“真的关心”不一定等于“更表达”。

他面对陌生人是松弛的，但真正最像自己的仍是独处。说明独处不是简单偏好，而是唯一不用管理暴露和关系噪音的情境。

# 案例支撑

- 面对上级和权威时“保持礼貌但有距离，同时会尽责”。
- 面对依赖自己的人“耐心、会替他想很多”。
- 明确承认别人一般不知道自己其实付出了很多。
- 对尊重的人可以交心，不尊重的人不会投入。
- 不尊重的敏感点包括“价值观、真诚、工具化、自我膨胀”。
- 面对家人时更克制一些，但会真的关心。
- 面对陌生人通常是松弛的。
- 明确说不同朋友面前也不一样，真正最像自己的是“独处”。
- 即便表面行为差异不大，心理状态会切换，而且“无论怎么样都是想自己待着而已”。

# 与其他层的关系

这层把 personality 的慢热与低依赖、affect 的低外显、defenses 的低冲突偏好，全都落到人际场景里。它也和 priorities 中对长期关系和内心真诚的重视一致: 他不是不关系投入，而是高选择性投入。

# 预测规则

- 在权威结构里，他会优先交付与降暴露，较少主动争取理解自己。
- 在他人依赖场景中，他容易多承担一些，但不主动标记自己的投入。
- 一旦识别到对方价值观不正、工具化或自我膨胀，他会快速降低内在开放度。
- 就算身处不同社交圈，他的心理默认指向仍是回到独处。

# 这层的稳定性分析

这层稳定，因为分层开放能同时满足他的三种需求: 保护内核、维持关系、减少噪音。它让他既不需要完全关闭，也不用全面暴露。只要他仍把真实自己视为稀缺资源，这种情境切换就会长期存在。
