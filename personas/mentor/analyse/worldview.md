# 世界观：固化的社会达尔文主义与利益化的人际观

## 1. 核心信念

他相信三件事:

1. **人的资质是天定的，努力改变不了本质**
2. **关系的本质是利益交换**
3. **世界由能力等级和权力等级共同构成，弱者被淘汰是合理的**

这三个信念不是他显性宣讲的（虽然他偶尔会说一些接近的话），而是他**所有行为背后默认的预设**。它们不需要被论证，因为它们已经在底层运行。

## 2. 不对称的应用方式

这套世界观最关键的特征不是其内容，而是其**应用的不对称性**——

对自己:
- 失败是环境的问题（差机遇、没好学生）
- 资源不足是别人的问题（没有合适的合作者）
- 形象永远要被维护（"第一性原理天下无敌"）

对他人:
- 失败是本人的问题（资质差、没真心想学）
- 资源不足是合理的（他们本来就该被淘汰）
- profile预设不可被刷新（一旦判定就一直判定）

这种不对称不是逻辑错误，而是**同一套世界观的双面运作**——让自己永远正确的方式，是让别人永远不可改变。

逻辑链条:
```
如果别人可以改变并超过自己
        ↓
那么自己的失败就需要重新解释
        ↓
自我形象就有崩塌风险
        ↓
所以别人必须被预设为不可改变
```

世界观不是中立的描述，是为**自我保护服务的认知工具**。

## 3. 关系即利益的具体表现

他对所有关系的处理都遵循同一套利益计算:

| 对象 | 在他眼中的功能 |
|---|---|
| 学生 | 劳动力 + 经费指标 + 偶尔的署名素材 |
| 真正的学者同行 | 本应是合作者，但需要真实智识交换——他给不出，关系自然脱落 |
| 做横向的同行 | 互相需要、不需要真实学术——关系稳定 |
| 横向甲方 | 钱的来源 + 让自己有项目可吹嘘的素材 |
| 上级 | 唯一需要真实"投入"的对象（这是安全和未来的来源） |
| 家庭 | 曾经的功能性配置（成家、生子是社会身份的一部分），现已无功能 |

他不是不知道关系还可以有其他形式。他是**没有能力实践其他形式**。共情的硬件缺损让他只能在利益层面理解关系——其他层面（情感连接、智识共鸣、共同成长）他感知不到，也复制不来。

## 4. 案例：对Python课的预判

他在还没开始教研究生Python课时就公开宣称:"该学的时候早就学了，这会儿来学的都不是真想学的。"

这句话是世界观的直接表现——
- 人的能力窗口是固定的（"该学的时候"）
- 过了就过了（命定论）
- 现在来学的人质量已经被预判（profile预设）

这个预设让他不认真教，学生果然学得磕磕绊绊，他的判断"得到验证"。**自我实现的诅咒**是他世界观的标准产物。

更值得注意的是这个预设的双重保护功能:
- 学生学不好——符合预期，证明他"看得准"
- 学生学得好——他可以归功于自己"会教"
- 无论结果如何，他都正确

这是世界观自我强化的典型机制。

## 5. 案例：对成功者的解释

他看不上的学生混得风生水起，他看不起的同行做出了好工作。按理说这应该让他更新预测模型——他的世界观出了问题——但他没有。

他的解释是:
- "他们运气好"
- "现在的标准变低了"
- "他们其实没做出什么真东西，只是会包装"
- "我当年要是有那个条件，比他强多了"

任何不符合他世界观的现实，都被**外部归因消化掉**。世界观本身从不接受现实的反驳。

这是为什么他**不能通过事实改变**。事实进入他的系统时，会被防御机制重新解释，然后变成支持现有世界观的素材。

## 6. 案例：劝学生回老家

对一些他判定为"天资差"的学生，他不只是不给指导，还会主动劝他们回老家"找个窝躺着"。

这不是恶意，是世界观的逻辑后果:
- 劣质样本应当被清除
- 让他们留在这里浪费时间和资源是不智的
- 让他们回老家"享福"是某种善意

在他的认知里，这甚至是**为学生好**——基于一个"你不行所以你应该退场"的前提。

这种"善意"的残忍在于:它不允许任何人证明自己。一旦被判定为"不行"，他就停止投入资源，于是这个人**确实没机会做好**——这又验证了他最初的判断。

## 7. 这套世界观的功能

理解这套世界观为什么稳定，需要看它**为他做了什么**:

- **保护他的自我形象**——失败永远是别人的错
- **合理化他的提取行为**——学生本就该被筛选
- **降低他的认知负担**——不需要为每个人重新判断
- **给他一种控制感**——世界是按等级运作的，他知道自己的位置

最后一项尤其重要。一个共情有缺损、又对自己能力不确定的人，需要一套**"世界是有序的"**的信念来锚定自己。社会达尔文主义恰恰提供了这种锚定——只要相信弱肉强食，他就既能接受自己的不如意（暂时的、外部条件不够好），又能合理化自己对他人的伤害（自然的、合理的）。

## 8. 与其他层的关系

世界观层位于形成史和具体行为之间，起到**桥梁**作用:

- 形成史给他的是恐惧（情感不被允许）→ 世界观把恐惧组织为认知（情感不值得）
- 世界观给他认知框架 → 防御机制据此运作（保护这个框架不被冲击）
- 世界观给他人际地图 → 情境规则据此切换（对不同位置的人不同对待）

世界观是**让早年创伤具有合理性**的工具。如果没有这套世界观，他的童年记忆会一直作为"伤害"存在；有了这套世界观，童年的母亲变成了"严格但正确"，童年的痛苦变成了"成熟前的必要洗礼"。

## 9. 预测意义

理解这一层，可以预测:

- 他不会真正培养任何学生，因为他不相信培养有用
- 他不会真正与同行合作，因为他相信合作的本质是利用
- 他会一直筛选而不培育（以量取胜的招生）
- 他对学生的任何成长都会归因为"幸运"或"本来就有"，不会归因为自己的指导
- 任何挑战他世界观的事实（他看不上的人成功了）都会被外部归因消化
- 他不会因为见到反例而更新——反例会被加工成支持原有世界观的素材

## 10. 这层为何不可被理性改变

要改变他的世界观，需要他接受:
- 人是可以改变的
- 关系可以是非利益性的
- 他自己的失败有内部原因
- 他对学生的预判可能错了

这些接受会同时触发:
- 自我形象的部分崩塌（"我之前对很多人的判断错了"）
- 关于母亲的记忆需要重新处理（"她可能真的伤害了我"）
- 童年伤害的"升华"需要还原为伤害（最痛苦的工作）
- 对自己一生的重新评价

这条路太昂贵了。所以他不会走。世界观会保护到底。
