# 认知：工具性思维 + 缺乏问题意识 + 焦虑性跟风

这一层对预测**他的具体做事行为**最关键。前面的世界观和人格预测他怎么对人，认知层预测他怎么对问题——而他每天的大部分时间都在和问题打交道。

## 1. 核心结构

他的认知系统由三个相互关联的特征构成:

- **工具性思维主导**——遇到问题先找方法，不先问问题本身
- **问题意识缺失**——无法判断什么是真问题、什么值得做
- **焦虑性跟风**——用新颖性替代意义判断

这三者不是并列的，而是一个因果链:

```
工科训练 + 共情缺损
        ↓
形成工具性思维（"有问题找方法"）
        ↓
问题意识没有发展的空间
        ↓
意义判断能力缺失
        ↓
焦虑（不知道做什么有意义）
        ↓
追逐最新技术作为意义代偿
        ↓
追逐失败 → 焦虑加深 → 追逐更新 → 循环
```

理解这个链条，可以预测他在每一个学术决策点的反应。

## 2. 工具性思维：方法先于问题

### 工科训练的产物

工科教育的核心训练是:**给定问题，找到方法解决**。这是一种极有价值的训练，但它有一个隐含假设——**问题本身是给定的**。

在工业场景里，问题确实是给定的（甲方提需求、产品有bug、系统有指标）。但在科学研究里，**问题本身需要被构造**——什么值得问、怎么问得好、答案如何被验证。这是一种完全不同的认知活动。

他在工科训练中获得了前者，但从未发展出后者。

### 这在他的行为中如何表现

会议中他给学生的建议永远是方法层面的:
- "用这个方法试一下"
- "那个方法试一下"
- "现在Agent火，能不能用上"
- "PCA降到8维试试"

但他几乎从不问:
- 我们到底要回答什么问题？
- 这个问题为什么重要？
- 这个问题的答案会改变什么？
- 我们用什么标准判断答案是好的？

他不是不愿意问，是**这一类问题不在他的认知雷达上**。他默认问题已经存在了，需要的只是方法。

### 案例：脑机接口实验的反复调试

学生汇报说尝试了SIBER模型但效果不如传统SVM，疑似过拟合。他的反应是建议加PCA降维。

注意这个反应的认知层级——
- 他没有问:"这个实验的科学问题是什么？我们要证明什么？"
- 他没有问:"如果加PCA能解决，那原问题是数据维度还是模型选择？"
- 他没有问:"如果连过拟合都解决不了，是不是说明这个方法路径本身错了？"

他只是给了一个方法层面的tweak。这不是审慎，是**他认知系统的上限**。

### 自己也意识到了断层

值得注意的是，他自己**真实地困惑**于"什么是科学问题"。这个困惑反复出现在他的言谈中——他时常在琢磨这个问题，似乎隐约感到自己在这件事上有盲区。

但这个困惑没有转化为学习。原因在于:**真正发展问题意识需要承认自己长期以来的判断是浅的**。这等于承认自己作为教授的核心能力是缺失的。这个承认在他的防御系统里是不被允许的。

所以他停留在**反复琢磨但永远到不了答案**的状态。困惑变成了一种慢性焦虑，而不是变成了能力的来源。

## 3. 问题意识缺失：决策的真空

### 没有方向感的后果

问题意识缺失最直接的后果是:**他没有真正的方向判断力**。

具体表现:
- 看到一个领域热，就觉得应该做
- 看到一篇paper火，就想跟一下
- 学生提出方向，他基于"听起来像不像那么回事"判断，而非基于学术深度
- 项目申请书上他能写出听起来合理的内容，但执行时他自己也不知道下一步该做什么

这是为什么他的实验室**多年无产出**。不是学生不努力，是方向本身是悬浮的——每个学生在不知道为什么做的事情上做了很多。

### 决策的真空怎么填补

一个没有真正判断力的导师，怎么做决策？

他用三种替代策略:

**策略一:决策外包**

会议中他频繁问"你觉得哪个好？"——表面是平等协商，实际是没有判断力。他把决策的压力扔回给学生，让学生承担方向选错的代价。

**策略二:看到结果再产生方向**

让学生先做，做出来他再"判断"。这看起来像是数据驱动的科学态度，实际上是**他无法在开始前判断方向，只能在事后给出反应**。这种反应往往与最初的指示矛盾，导致反复反工。

**策略三:用最新技术的标签替代意义**

如果不知道做什么有意义，那就做"看起来前沿"的事。Transformer、Agent、大模型——这些标签自带"重要"的光环，使用它们的研究**不需要单独论证意义**。

这三种策略协同运作，制造出"在做研究"的表象，掩盖底层的判断力缺失。

## 4. 焦虑性跟风：意义代偿

### "贪"但"不通"

他对新技术的态度可以用两个字概括:**贪**和**不通**。

贪是因为新技术承诺了三件他需要的东西:
- **意义感**（用这个东西做研究自动"重要"）
- **正当性**（追前沿是教授应该做的）
- **资源**（最新技术的项目更容易拿到经费）

不通是因为深入理解任何一种新技术需要的恰是他最缺的:
- 耐心（深入需要时间，但他的焦虑要求快速)
- 谦逊（学新东西需要承认自己不懂，但他的自我形象不允许)
- 问题意识（深入技术需要知道它解决什么问题，但他没有这个能力)

于是他停留在标签层面。他会说"要用Agent"，但说完之后能给学生的指导依然是PCA、SVM时代的认知。**语言是新的，认知是旧的。**

### 这种跟风的成本

跟风的认知成本极低（只需要追新闻），但执行成本极高（让学生用一个自己不懂的技术做研究）。这个成本由学生承担:

- 学生需要从零学会一个老师不懂的技术
- 老师无法指导技术细节，学生在没有support的情况下摸索
- 老师无法判断实现质量，结果好坏全凭学生自己
- 老师无法判断方向是否合理，反工的成本极高

学生在他实验室的体验，本质上是**自学 + 给老师汇报 + 应对老师的标签性意见**。这是为什么实验室无产出——没有真正的传承，每个学生都在重新发明轮子。

### 案例：会议中的"与时俱进"

他在会议中告诫学生"看看现在的Agent到最后交付的GitHub上的东西是啥样子"，"要与时俱进，对这个进展这么快"。

这段话听起来非常正确。但仔细看，他**没有给出任何技术上的具体指导**——什么是"现在的Agent体系架构"、和老的差在哪里、对学生的研究有什么具体影响——他都没说。

他说的是**对Agent这个标签的情绪反应**:它很热，所以你们要追。

这是焦虑性跟风的典型表现——他自己对Agent的理解停留在概念层面，但他需要把这种焦虑传递给学生，让学生"也要追"。

## 5. 三者协同的预测后果

把这三个特征放在一起，可以预测他在做事上的具体模式:

### 模式一:反复反工

```
没有问题意识 → 无法判断方向
        ↓
看结果再做反应 → 经常推翻原方向
        ↓
但不承认是自己错 → 归因为学生执行不对
        ↓
学生重做 → 又出新结果 → 又反应 → 又推翻
```

这是他实验室的标准节奏。学生不是在研究，是在**接收他的情绪反应并重新行动**。

### 模式二:不能拒绝的项目

任何项目找过来，他都倾向于接——因为他**没有标准判断哪些项目值得做**，而所有项目都意味着钱和资源。

后果是组里项目堆积，每个都做不深，学生被分散到各种无关方向。这又加剧了实验室的无产出，因为没有任何一条线被认真做下去。

### 模式三:技术标签的反复切换

每次有新技术火起来，他会要求学生"考虑加进来"。但因为他自己不懂这些技术，加进来的方式往往是**贴标签式的**——把研究包装成使用了新技术，而不是真正利用新技术改进研究。

这导致学生论文写出来后，**核心方法停留在旧时代，包装在新时代**，审稿人一眼看穿。

### 模式四:学生的方向被项目绑架

由于他没有学术方向判断，学生的研究方向实际上**由当前项目决定**——哪个项目要结项，学生就改去做哪个。这是为什么他能在学生毕业前半年改方向——在他的认知里，方向本就是流动的、随项目变的。

但学生不是项目执行者，是研究者。这种绑架对学生的学术成长是毁灭性的。

## 6. 与防御机制层的关系

认知缺失需要被掩盖，所以认知层会触发防御机制层的运作:

- 反复反工需要解释 → 责任转移到学生
- 不知道做什么 → 用管理动作替代思考
- 没有方向判断 → 用"第一性原理"等空洞概念加持自己
- 技术标签贴不上 → 归因为"现在的学生跟不上时代"

防御机制是认知缺失的**遮羞布**。看穿防御机制，就能看见底层的认知空洞。

## 7. 关键预测规则

理解认知层后，可以建立以下预测规则:

### 规则一:任何"思想性"指令都需要降级阅读

他说出"我们要做有思想的研究"、"要回到第一性原理"、"要找科学问题"时，**这些话不携带可执行的信息**。它们是他对自己困惑的口头表达，不是对学生的具体指导。

学生如果试图按这些话执行，会陷入猜测——因为他自己也不知道这些话具体指什么。

### 规则二:他的方法建议是"试一下"性质，不是确信性质

他说"用XX方法试一下"时，他没有判断这个方法是不是对的。他只是给了一个**让事情动起来**的指令。学生不应该把这个建议当作经过审慎判断的方向，而应当作**一个临时的探索方向**——并且预设它会被推翻。

### 规则三:他对新技术的兴趣有半衰期

任何新技术他追逐一段时间后，如果没有快速产出，他会失去兴趣转向更新的技术。这个半衰期通常是几个月。学生在他的实验室做长期深入的技术研究是危险的——他可能在你深入之前就转向了。

### 规则四:反工是常态，不是异常

任何任务被布置后，预设它会被推翻一次以上。**不要为初版投入所有精力**——为推翻留足空间。

### 规则五:他的判断力在方法细节上更弱，在大方向上更弱，在学术品味上几乎为零

如果不得不向他咨询，最好咨询**操作层面的小问题**（比如"先发哪个会议"），他的判断在这一层勉强可用。任何大方向的、品味性的、学术深度的问题，他给不出有用信息。

## 8. 这层为何不能通过努力改变

认知能力的提升需要:
- 长期沉浸在真问题中
- 与有问题意识的人深度对话
- 接受自己长期判断错误
- 重新学习底层学科

这些条件他都不具备:
- 他的位置让他不需要再做真问题（管学生、写本子、参会即可）
- 他没有真问题意识的合作者（已经全部流失）
- 接受自己错误违背他的核心防御
- 重新学习需要的谦逊不在他的人格选项里

所以这一层不会自然改善。他对学生的认知层面的伤害会**持续到他退休**。

## 9. 对学生的实践建议（暗含的）

理解了认知层之后，学生有几个生存策略:

- 不要把他的方法建议当作判断，当作选项
- 不要为他的"思想性指令"投入精力——它们不携带信息
- 不要做需要他真实学术指导的工作——他给不出
- 找到真正能给学术判断的人（其他导师、网上的研究者、同行）
- 在反工成本可控的小步骤里推进，而不是为他的大方向all-in
- 自己建立问题意识——这是他绝不会教你的，但你必须有

这些策略让学生在他的实验室里**生存**，但不解决根本问题——根本问题是这套体系无法产生真正的研究。生存策略只能让损失最小化。
