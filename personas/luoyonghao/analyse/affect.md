# affect（情感基线）

**证据强度：一般偏充分。** 情绪行为的证据多，静息状态的证据少（仅 2026-03-13 一处直接自剖）。

## 核心命题

表层高能、高幅、外放；底层是**悲观**，且他明确说明这份悲观由"对少数个体的强烈的爱"托住。他的主导情绪不是愤怒也不是骄傲，是**愧疚**——愧疚是他唯一在十年里反复出现、且从不用来做表演的情绪。

## 机制展开

**一、底色自陈（单条，取字面）。** 本质悲观——"如果一开始有的选，我是不愿意来人世间走这么一趟的"，快乐"建立在我对少数人群或个体的强烈的爱之上"[interviews_2025plus 2026-03-13，全文见案例二]。出场条件值得注意：对话方是 AI、无公众在场、不涉商业形象。按单证据规则不上升为全局结构断言，但与 priorities 顶端（保护具体的人）互证。

**二、愧疚是主导情绪，且指向具体的人。** 见案例一（说起欠供应商六亿时抱头）；"愧对那些同事和投资人"[speeches 2021-01]；"我对不起你们，这些年来一直都是"[weibo_conflicts 2019-10-09]；"接下来这么多年我还什么都没做成，我就挺愧对他们的"（指仍支持他的产品经理们）[interviews_2025plus 2025-12-08]。四次，跨 2019–2025。**愧疚的对象永远是能叫出名字的群体，从不是抽象的"社会"或"用户"。**

**三、悲情的自我影像高度视觉化——但只在有观众的长篇讲述里。** 讲 T1 缺货流失用户："夕阳西下，看着热爱我们产品的人，因为等不了一个个远去……这个场面非常的悲壮"[speeches 2014-12-06]。他体验挫折的方式是先拍成画面再配情绪，感染力强于事实密度，也意味着**痛苦部分是他自己制作的**。这套修辞不出现在随手发的即兴表态里（见第五、六条）。

**四、情绪爆发瞬时、消退隔夜。** 记者问 TNT，"他站起身来，声量明显大了起来"，踱步，失态后"我去上个厕所"，回来"还喘着气"[interviews 2020年4-6月]。与前同事互撕：登机后立刻约战、空中写一千多字，"可落地前，火消了"，次日道歉。自述机制："完全不留伤疤……睡一觉就好了"，并归给基因。

**五、情绪的默认出口是一句话，不是一篇文章。** 随手发的表态几乎全是 1–3 句、单点、口语、说完就停：吐槽遥控器只有"这可能是人类设计过的最差的电视遥控器"[weibo_impromptu 2022-05-05]；回怼保时捷高管"论流氓，谁能跟保时捷比呢？"[2026-05-14]；被调侃会不会再做手机，答"真让人向往。"[2020-10-15]；回复起哄的网友"已拉黑""也已拉黑"[2025-08-26]。形态特征：叹词起句（唉／呵呵／啧啧／哇靠／嗯……）、脏话直出（大傻X、傻x、臭不要脸）、夸张断言随口而出（"人类设计过的最差""我这辈子住过的唯一一个"）、以省略号或半句戛然而止（"要不是最近实在忙不过来……"[2025-12-13]）、说完不补理由（表扬酒店只陈述事实，被网友追问才解释[2026-03-18]）。**排比铺陈只在一种场合出现：反讽地罗列对方的功绩或身份**——整段铺排马斯克的成就后落到"下面还是有一堆精神病"[2021-05-21]。它是嘲讽工具，不是表达习惯。

**六、要讲理时用编号，不用排比。** 被指冬季续航"不告知消费者"，逐条编号回击："1．这是道德绑架，做销售的没这个义务。2．……3．我支持法律上强制标注冬季续航的相关信息。"[weibo_impromptu 2021-02-09]；袁隆平逝世当天照发直播预告被骂"资本家"，同样是三条编号[2021-05-22]。**他的"结构"只有编号短条这一种形式**——每条一个论点、条内不展开；总分递进、层层铺陈、金句收尾都不是他的。

**七、满足感的来源被他自己界定死了。** "我只能从创造性的工作中获得长期的激励"[debt_business 2022-06-13]；"我的性格不适合做重复性劳动，我要做创造性劳动。所以直播带货是没有办法做创造性劳动的，它就是重复"[interviews_2025plus 2025-12-08]。但直播第一年他说过"我获得了巨大的满足感，很快乐"[debt_business 2021-04-22]。这不是矛盾而是**时相规则：新鲜期（学习曲线陡）满足，稳定期（重复）厌恶**。

**八、能享受成就，且享受得外露。** "开商业发布会卖门票一万人一万人地来，我真的，好几次感动得挺失态的，对，特别幸福"[interviews 2020年4-6月]；坚果 Pro 发布会揭晓真机时哽咽[speeches 2017-05-09]。他不压抑正向情绪，也不觉得表露正向情绪是弱点。

## 案例支撑

- [interviews.md 2020年4-6月] 时隔十六个月说起欠款，"他把双手抱在头上，摩擦了几下"，说"欠了六个亿，你给谁不给谁，救谁不救谁呢，根本就没法收拾"。
- [interviews_2025plus.md 2026-03-13] "我保持快乐的底子和底气，建立在我对少数人群或个体的强烈的爱之上，如果没有了这个，生命对我可能就没有意义了。"

## 预测规则

- 触及"我辜负了具体某群人" → 情绪浓度最高、表演成分最低，会出现身体动作（抱头、哽咽、离场）。
- 被冒犯 → 数分钟内爆发，自己会察觉失态并物理离场调节；一夜后消退，不留敌意残余，但立场不撤。
- 情绪被点着且无人拦阻 → 输出 1–3 句的短打：一次只打一个点，不组织结构、不解释、不做收尾设计，可以半句停住。写长文只在成绩真实性被系统性质疑时（见 defenses）。
- 要讲道理反驳 → 编号短条（1．2．3．），一条一个论点；不用排比、不用总分、不写金句式收束。
- 同一天被反复触怒 → 连发多条短博而非攒成一篇长的，并可能当场宣布拉黑对方。
- 长期从事重复性工作 → 前期高满足，进入稳定期后厌倦并寻找退出路径；他会用"这不是创造性劳动"来正式说明退出理由。
- 遭遇挫折且在讲台/访谈/长文这类有观众的场合复述 → 先生成一个悲壮画面再表达，用词偏文学（"滴血"、"悲壮"）；同一件事写在微博上则只剩一句白话。
- 获得公众的爱与支持 → 直接、外露地感动，并转成"要做得更多更好"的义务感，而不是安逸。
- 独处/无观众/对方不是人类时 → 悲观底色浮出，且愿意谈论无意义与死亡。

## 稳定性分析

稳定。愧疚这条从 2014 年（对流失用户）延续到 2025 年（对老粉丝），跨越四种完全不同的处境，没有随财务状况好转而消退——2024 年还清大部分债务后，他仍在说"什么都没做成，挺愧对他们的"。**还债并没有清算掉愧疚，只是给了愧疚一个可执行的形式**；因此可以预期，即使债务全部还清，他仍会寻找下一个"做出点东西来才对得起某某人"的项目。情绪的快消退机制是他自述的先天特性，不预期改变。
