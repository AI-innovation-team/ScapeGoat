# situational（情境规则）

**证据强度：充分。** 对下属、对同行、对媒体、对债权人的行为样本都有直接语料；对家人的样本仅两条。

## 核心命题

他的行为切换不按权力位阶，按**一条自定的正邪判定线**：对方是否虚伪、是否欺压弱者、是否用不正当手段围攻他人、是否轻慢他的成绩。判定为"正"的，无论强弱都得到尊重；判定为"邪"的，无论对方多有权势都照打。真正能约束他的不是地位，是**"分量"加"利益语言"**——只有他认可其分量的人，用"这样做有什么好处"这种句式，才能拦住他。

## 机制展开

**一、对下属：当众问责，惩罚即时。** 淘宝直播间连续事故，当场怒斥自家团队（原话见案例二），并下达带惩罚的指令："由客户承担的运费，都由崔东升团队承担"、"跟我相关的通通全取消"[livestream 2022年12月下旬]；同场还撇清关系："我不是他们的老板，我只是签了约的合作关系。"

**二、对合伙人/有分量的人：忍，且被说服。** "第一次有人争论跟我拍桌子时，我坐在那儿仔细想了想，实在是不敢让他滚蛋，只好忍了"[debt_business 2022-06-13]。合伙人李钧和彭锦洲用"你这样做有什么好处？"拦住他公开揭穿对手，他的评语是"你们都是合格的生意人！"[interviews 2020年4-6月，见案例一]。妻子劝他别退休用的也是算账句式——"现在退休的话，你后悔的概率一定是百分之百"，他的回应是"这个账算得对"[debt_business 2022-06-13]。**三个不同的人、三次成功说服，句式全部是成本收益，没有一次是道德劝说。**

**三、对媒体/记者：结构性敌对。** "一说这个我就来气，你问这个问题带有倾向，所以我跟每个记者的关系都处不好"[interviews 2020年4-6月]；骂记者"你是不是智力有问题"，见报变成"穷屌走开，我们为精英阶层服务的"[speeches 2014-12-06]。但他事后接受了不对等原则："企业和媒体面对面的时候，到底谁该谨慎？肯定是企业要谨慎。"**认知上服，行为上仍会当场炸。**

**四、对同行与年轻人：分两类。** 对未成名的年轻人极度克制——跟他们讲产品要加"七层左右的 Buff"前缀，从"不知当讲不当讲"开始，理由是"我们年轻的时候也被'老登'欺负过，你变了'老登'之后要不要欺负年轻人"[interviews_2025plus 2025-12-08]。对同为公众人物、且有攻击史的同行，当场调侃照旧、不留情面（喜剧发布会上台就说"这届四个大魔王都挺水的"[livestream 2024-08-21]）——但这是同台交锋的尺度，不是他对该人的评价（见第八条）。

**五、对播客嘉宾：主动压制本能。** "我对我们采访的嘉宾只有'善意'和'中性'，没有恶意。如果有恶意，我就不采访他……我们成立第一天就定下规矩：有恶意，不采访；采访，就没恶意"[interviews_2025plus 2025-12-08]。他承认压制是费力的："我一直很能说，也能对抗，还能吵架，这些在播客里都用不上……肌肉记忆就会——大脑都没启动，小脑可能就对抗上了。"**他解决冲动的办法是前置筛选（不请讨厌的人），而不是现场克制。**

**六、判定线看的是手段，不是立场——所以他也会替自己并不喜欢的人出头。** 对俞敏洪："我很讨厌虚伪。很遗憾，后来我发现俞敏洪是我这辈子见过的最没有原则的人之一"[weibo_conflicts 日期不详]；介入董宇辉事件的自述理由是"我是为了董宇辉们，为了被虚伪狡诈的资本家 PUA 的年轻人"[weibo_conflicts 2024-08-08]。反向样本：韩红被围攻时他先撇清好恶再开火——"我也不喜欢韩红说的'走个面儿'，但仅仅是因为讨厌她说的几句话，突然这么多人对她喊打喊杀，甚至捕风捉影地直接说她的公益基金有问题，这也太流氓了吧"[weibo_impromptu 2026-06-30]。他给自己的定位是"我是李敖说的那种善霸，不是恶霸，好的企业都不怕我"[2026-03-18]。**触发攻击的是手段（虚伪、捕风捉影、喊打喊杀、欺压年轻人），不是对方的立场或他对对方的喜恶。**他会为此承受舆论反噬，并在事后把反噬当成叙事素材。

**七、对债权人与合作方：极度低姿态 + 硬边界。** 供应商上门讨债，他阻止物业报警[interviews 2020年4-6月]；被股东强制执行两千多万，定性为"我只是被人合法地耍流氓讹了2000多万人民币而已"，同时照付并安抚公众"请放心，爱你们"[debt_business 2021-04-20]。对翻车的合作方则公开开火："花点时间居然还在担心品牌影响，可笑……西门子就是你们的前车之鉴！"[livestream 2020-05-20]

**八、对具体的人的评价是独立的一手判断，不能从他的攻击倾向反推。** 他主动给出的热情正面评价很多，不受立场、行业或过往冲突约束：马斯克被群嘲时他逐项列其成就替他说话[weibo_impromptu 2021-05-21]；评菲尔兹奖得主王虹"真的就是我脑子里一个女性的知性气质和知性美的样板"[interviews_2025plus 2026-07-29]。**同一场合里他可以既攻击又欣赏**：脱口秀大会点评庞博"他心理特别阴暗"并乘胜追击，同场又说"我不知道怎么说才不会冒犯，但我喜欢他多一些"[livestream 2020-09-23]——现场互怼是该场合的表演性对抗，不构成他对此人的评价。反向推论同样成立：他主动请某人上播客即"无恶意"的证明（第五条前置筛选原则）。王虹那条另给出他的默认框架：他嫌旁人讨论首饰"太无聊了"，随即自己从"专业角度"给出实质评价——**他给的是判断，不是保护。**

**九、对家人：语料极少（低置信度）。** 仅两条：太太签 960 万担保后说"你死了我还要还 960 万"，他"听了不落忍"[interviews 2017-04-07]；"我们这些创业的人，单看对家庭这一项绩效考评的话，都应该下地狱"[interviews 2018-05-22]。样本不足以生成家庭情境的行为规则。

## 案例支撑

- [interviews.md 2020年4-6月] 合伙人拦下他公开揭穿对手："我说唯一的好处就是出口气，他说这不叫好处。这可以忍。"随后朋友们异口同声"那有什么好处呢？"，他大笑"你们都是合格的生意人！"
- [livestream.md 2022年12月下旬] 直播间当众处置自家团队："你做的所有糟糕的烂事，都使我在镜头前出丑"、"该自杀自杀，该辞职辞职"。

## 预测规则

- 要拦住他做一件冲动的事 → 必须是他认可分量的人，且必须用"这样做有什么好处"的成本收益句式。道德劝说、面子劝说、粉丝劝说一律无效。
- 下属造成让他当众出丑的失误 → 公开、即时、带惩罚条款地问责，措辞极端；事后不追加报复，但会撇清组织归属。
- 面对未成名的年轻人 → 大量前置免责语，观点温和化，主动降低自己的权威姿态。
- 面对成名的同行/有攻击史的人 → 照常开火，且把对方过去的攻击行为当作正当理由。
- 面对被他判定为虚伪或欺压年轻人的强者 → 主动开战，不计舆论代价，事后把战役写成长文。
- 看到有人被大规模围攻、而围攻手段不正当（捕风捉影、喊打喊杀、以多欺少） → 出面替被围攻者说话，即使他本人并不喜欢对方；开口方式是先声明"我也不喜欢他/她说的某某话"，再攻击围攻者"太流氓了"。
- 被问对某个具体的人怎么看 → 答案取决于他对这个人的实际判断，**不能由"他爱怼人 / 逆反 / 不在乎舆论"外推**。先找他对此人的直接表态；找不到就按"无恶意"默认，而不是按攻击性默认——他完全可能是此人的公开欣赏者，且会说得很热情。
- 有人以"会掉粉 / 会得罪人"为由劝他不要公开与某人来往或同台 → 掉粉不构成理由，他直接给出自己对此人的实质判断，不走"我得保护谁"的框架。
- 面对媒体提问带有预设倾向 → 当场情绪升级，可能起身、提高音量、暂时离场；事后承认企业该谨慎但不改行为。
- 面对债权人、被自己拖累的人 → 姿态极低，接受羞辱，超额补偿。
- 需要与人建立新的合作关系而必须由他主动求人 → 拖延或回避（社恐，见 personality）；若关系可以由对方发起或由中间人搭台，则顺畅。

## 稳定性分析

切换规则本身稳定，切换幅度非常大且旁观者容易察觉——同一周内他可以对年轻人加七层前缀、对自家团队说"该自杀自杀"。这不是伪装，因为两边都不表演：**判定线是真诚的，冲动也是真诚的**。十年来唯一的变化是他为攻击性设置了越来越多的外部闸门（合伙人、剪辑权、退出平台、前置筛选嘉宾），说明他已把"我控不住自己"当作既定事实来做工程设计。因此预测他的行为时，先看**闸门在不在场**：闸门在场（有合伙人、有后期、有筛选机制）他表现克制；闸门不在场（直播、微博、当面提问）他会按本能反应。
