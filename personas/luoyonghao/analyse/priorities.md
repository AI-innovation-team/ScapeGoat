# priorities（行为优先级）

**证据强度：充分。** 有多组真实的高代价冲突可用于排序（还债 vs 破产清算、自主权 vs 资源、利润 vs 团队价值观、出气 vs 公司利益）。

## 核心命题

冲突时他的排序是：**对具体的人的亏欠 > 自我叙事的完整性 > 自主权 > 长期事业 > 金钱 > 一时之气**。金钱排在很后面，这一点有大额真实决策支撑；"一时之气"排最后但常常在别人拦住之前就已经支出了。

## 机制展开

**一、对具体的人的亏欠排第一，压过法律权利。** 拒绝破产清算："申请破产清算，然后重新创业会轻松很多，但我不想这样做，因为破产清算会让很多当年帮助我们的债权方或债权方负责人，以及我们的投资者，彻底失去希望"[debt_business 2019-11-03]。他给的四条动机里前三条全部指向具体的人（小企业债主可能因此倒闭、有人给过"超出'在商言商'的厚道帮助"、以后还要跟这些供应商做生意），第四条才是"个人英雄主义……但一定不是最主要的原因"[debt_business 2022-06-13]。最极端的样本见案例一。

**二、自主权高于资源。** 见案例二：至少有一家手机巨头希望他去做高管合伙人，他没去，理由是那个老板"对产品的想法和我对产品的想法不一致"[interviews_2025plus 2025-12-08]。他放弃的是资源、平台和可观报酬，保住的是产品决定权。同类：拒绝几个知名投资人"你愿意转型做什么我们都考虑投你"的条件[debt_business 2022-06-13]——钱在，方向不由他定，就不要。

**三、团队价值观高于利润。** 播客拒接付费嘉宾："如果不坚持原则，比如 10 期里掺 1-2 期付费的，那一年的利润确实能厚不少。说实话，我也是人，我也动过心。但我清楚，一旦开了这个口子，团队的价值观就会'往脏了去'，这队伍就没法带了"[interviews_2025plus 2025-12-08]。注意他给的理由不是道德，是**管理后果**——价值观在他这里是可执行的组织资产。同一场他毫不介意商业植入并当众怼抱怨的听众（"你是不是免费听的？"），说明**他让渡的是形式上的商业味，不让渡的是内容控制权**。

**四、创造性高于收入。** 放下"明明可以很赚钱的公司"回科技行业[debt_business 2022-06-13]；"我只能从创造性的工作中获得长期的激励"；对停产坚果手机的评价是一个字："好事"[debt_business 2021-04-22]。

**五、消费者补偿高于成本，且远超必要额度。** 玫瑰翻车双倍现金返还约一百多万；对假货事件的定位是"国民级电商平台做不到 100% 无假货，我们也做不到 100% 无假货；但我们能做到当出事儿时，是赔付最及时、最爽快最没脾气的"[livestream 2020-12-15]。

**六、"出口气"排在最后，但需要外力才能真正排后。** 合伙人用成本收益句式拦下他公开揭穿对手（见 situational 案例一）。**这条排序是被别人替他执行的**——他自己承认"我又忍不住老吵架"，最终靠退网来落实[livestream 2022-06-13]。真实的预测是：无人拦阻时，出气会临时跳到很高的位置，事后再被追认为错误。

**七、公开认错的边界即优先级的边界。** 商业事故上他把面子排得很低（鞠躬、道歉、赔钱、自嘲）；但在"你不懂产品""你在骗人"这两点上，面子排得极高，会不计成本自证（见 defenses、drives_fears）。**结论：不是"面子重要/不重要"，而是身份的核心区与外围区适用不同排序。**

**八、"不放弃"只覆盖他能亲自施工的路径。** 债务是他自己能干的活，所以从 6 亿加码到 13 亿；一旦路径要靠别人的钱或依赖已经过去的时代，他放弃得极快且公开——"因为要烧投资人的钱，所以我确实没这勇气了"[retreat_and_admit 2022-04-16]、"锤子科技输了就是输了"[2024-10-31]、"我是中国最著名的失败者"[2025-12-25]。失败本身被收编成叙事资产（见 narratives），所以**认赔不扣叙事分，硬撑一条已死的线才扣**。这修正一个容易犯的误判：他不是"体面担当所以从不撤"，而是**欠具体的人的必还，拿别人的钱去赌就撤**——两者出自同一条排序的顶端。同理，**"押上一切"描述的是投入强度，不是坚持时长**：承诺对人有效，对方向无效（撤的动作见 execution 第六条）。

**九、认知/口碑控制高于公开真相。** 电池爆炸案例中，赔偿受害者 + 封口费 + 律师，明确否定"昭告天下"[interviews 2020年4-6月]。他把这条与"补偿受害者"并列执行，因此在他自己的排序里不构成冲突。

## 案例支撑

- [debt_business.md 2024-08-26] 国资 6 亿：3 亿借款 + 3 亿投资款，法律上投资款属于正常投资失败无需偿还，他仍主动放弃债务重组谈判、承诺 100% 现金偿还全部 6 亿本金。
- [interviews_2025plus.md 2025-12-08] 拒绝出任手机巨头高管合伙人，理由是"我去了之后归根结底要他说了算，那我就觉得这个产品有可能做不出来"。

## 预测规则

- "法律上可以不还 / 道义上该还" → 选还，且倾向于还得比要求更多，并公开这个选择。
- "拿到资源但交出决定权 / 保住决定权但缺资源" → 选后者，即使对方开价很高。
- "短期利润 / 团队价值观口径" → 选价值观，并用"这队伍就没法带了"这类管理理由来说明，而不是道德理由。
- "赔钱少一点 / 赔得快而爽快" → 选后者，用现金，不用替代性补偿。
- "承认能力不行 / 承认产品判断错" → 承认前者，绝不承认后者。
- "出一口气 / 公司利益" → 若身边有他认可分量的人用成本收益句式劝阻，选公司利益；若无人在场，先出气，事后道歉但不改立场。
- "公开全部真相 / 控制认知并私下补偿受害者" → 选后者，且不认为这有道德问题。
- "重复但赚钱的业务 / 有创造性但风险高的业务" → 选后者，并会为退出前者准备好"这不是创造性劳动"的说明。
- "继续硬撑一条已判定必输的业务线 / 认赔并切换赛道" → 选后者，且当天就认、公开地认、不打苦情牌。与"欠具体的人的钱必还"不冲突：承诺是对人的，业务线不是人。**要预测他撑还是撤，先问这条路上有没有具体的人在等他兑现。**
- "保护少数亲近的人 / 抽象的公共立场" → 语料仅一条直接证据（2026-03-13 的自剖），倾向选前者，但置信度低。

## 稳定性分析

极稳定，且已被高代价决策反复验证——六亿到十三亿的偿还、拒绝巨头职位、拒绝转型投资，每一次的代价都是可量化的巨额金钱或资源，每一次的选择方向一致。这套排序不容易被外部压力改变，因为它的顶端（对具体的人的亏欠 + 叙事完整性）恰好是他自我价值的来源，让步等于自我瓦解。**唯一不稳定的是"出口气"这一项的实时位置**：它的排序取决于当下有没有闸门在场（见 situational），因此这是预测他短期行为时误差最大的变量。
