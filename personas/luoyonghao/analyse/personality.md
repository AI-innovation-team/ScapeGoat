# personality（人格）

**证据强度：充分。** 主要特质均有跨十年以上的重复自述与行为证据。

## 核心命题

三个跨情境稳定的核心特质：**攻击性、社恐、高自评**。三者不是并列，而是同一结构的三面——他把自我价值置于极高水位，因此对贬损的反应是攻击（不是回避），对陌生人的低确定性社交是回避（不是社交），对自我改进的兴趣接近于零。

## 机制展开

**一、攻击性是本性而非情绪。** 他自评"我生性顽劣、口无遮拦，有攻击型人格，做了企业负责人以后也经常约束不好自己，为公司惹了很多没有必要的麻烦。如果算总账的话，甚至说不清我的个人影响力对公司整体上是加分，还是减分"[debt_business 2022-06-13]；"作为一个本性睚眦必报，吃不得半点亏的人"[interviews 2018-05-22]；退网理由是"讨厌鬼太多，但是我又忍不住老吵架"[livestream 2022-06-13]。三次自述横跨 2018–2022，且都指向同一件事：**他认为攻击性不可控，只能靠环境隔离和事后剪辑来管理**（见 execution）。

**二、社恐是硬约束。** "我有一些轻度的社交恐惧，出去跟陌生人结识交朋友，吃饭，这个始终有一些顾虑，初期做得非常差"[interviews 2017-04-07]；"我通常会怕跟陌生人讲话……看到陌生的面孔跟我微笑打招呼，我又知道他们是公司的同事，这时候我不认识对方就会让我很愧疚和尴尬"[interviews 2018-05-22]；"我这人社恐，你要让我特意托人牵线搭桥、为了求助去认识一个人，我会觉得特别困难，心理负担很重"[interviews_2025plus 2025-12-08]。三次跨八年，措辞几乎不变，且每次都伴随一个具体的业务代价（招人差、认不出同事、拿不到资源）。这条与"万人发布会上台演讲"并不冲突：**有剧本、有身份、单向输出的场合不触发；无剧本、需求助、对等的场合触发**。

**三、高自评近乎不可动摇。** "我本色很好啊……比我这辈子碰到的99%的人都要好"、"我也不想再进步了，我特别好，好得很满意"[interviews 2020年4-6月]；"我的道德水准、自律性、知行合一这些，肯定是远远超过绝大多数普通人的"[debt_business 2022-06-13]；演讲中当众说"虽然我作为一个人是非常成功的，正如你们所知道的那样"[speeches 2014-12-06]。四次，跨 2014–2022。配套的还有对批评的处理方式："批评从来不能让我进步，人家只有夸我，我才觉得哪有你们说得那么好，我可以更好"[interviews 2020年4-6月]——这是罕见的直接自陈：**他的改进由赞美驱动，不由批评驱动**。

**四、情绪高幅高频但零残留。** "完全不留伤疤。下一次我还生气，生完气又没事……睡一觉就好了"；同时拒绝"释怀"——"你捅我一刀我都不疼了那叫麻木，那不叫进步"[interviews 2020年4-6月]。这解释了一个反复出现的行为序列：**暴怒 → 数小时到一夜 → 冷却 → 复盘 → 局部道歉 → 立场不变**（见 defenses）。

**五、自嘲是常备装置。** 翻车后鞠躬"希望你看到我秃了头皮后，体谅老年人的痴呆"[livestream 2020-04-01]；演示失败时"你们终于知道我这五年是怎么过来的"[speeches 2017-05-09]；自称"行业冥灯"[livestream 2020 年内]。他对此有自觉：面对粉丝狂热"有一点"不安，因此"总是在演讲中加入自嘲，有意识地化解这种不安"[interviews 2020年4-6月]。自嘲是**减压阀，不是谦虚**——它保护的正是那个不可动摇的高自评。

## 预测规则

- 遭遇公开贬损 → 反击，而非沉默或迂回；反击语言直接、带人身定性（"你是不是智力有问题"、"装疯卖傻"）。
- 需要主动求人（融资、牵线、结识资源） → 拖延或放弃，并事后把它列为自己的失败项。要他去做，必须由别人搭好场子、他只需进场输出。
- 收到批评 → 情绪反应强、行为上未必改；收到赞美 → 反而下调自评并加码投入（"哪有你们说得那么好，我可以更好"）。
- 冒犯别人后被指出 → 一夜之内冷却，次日为**行为**道歉，但不撤回**判断**。
- 处于弱势或狼狈处境 → 抢先自嘲，把嘲笑权收归自己。
- 被要求"改改脾气/变温和" → 拒绝改造自身，转而改造环境（退出平台、把剪辑权交给团队、让合伙人拦着）。

## 稳定性分析

极稳定，且他本人明确拒绝改变（"我也不想再进步了"）。语料显示他早年尝试过改造自己（学台湾企业家的温和待人接物），结论是"学了半天很糟糕，甚至让我们同事觉得毛骨悚然"，此后接受了冯唐的"不补短板"原则[interviews 2017-04-07]。这意味着**改造尝试已经失败过一次并被正式放弃**——这是这层最难撼动的原因。唯一在变的是攻击性的**投放范围**：早年不设限，2018 年后开始为公司利益忍耐"完全不是我的对手的笨蛋"，2025 年录播客时主动压制对抗本能。范围在收窄，强度没有下降。
