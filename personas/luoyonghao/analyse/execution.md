# execution（执行模式）

**证据强度：一般。** 他对自己执行方式的自评很多，第三方可核对的具体管理动作较少（主要来自 T1 量产期、直播间事故、播客制作三处）。

## 核心命题

**战术层高强度、战略层长期缺位**——这是他自己的原话定性，且十年后仍成立。他的执行方式是：亲自扎进产品细节，用清单和例会硬啃问题，在方向层面则依赖直觉与类比（见 cognition）。他解决自身执行缺陷的办法不是补能力，是**建立外部闸门**。

## 机制展开

**一、自评：三件最重要的事都不及格。** "找钱、找人、定战略方向，对一个企业最重要的就是这三项……我战术上勤奋战略上面懒惰，这么看，直到今天这三个做得都不是很好，是不及格的"[interviews 2017-04-07]。找钱弱到"是投资人产生了错觉"；找人前三年"很业余"，总监以上全靠自己找，且被社恐拖累。这三条到 2022 年仍被他复述为教训[debt_business 2022-06-13]。

**二、CEO 的正确工作 = 抠产品。** "苹果做得那么好，是跟乔布斯本人每天跟产品经理坐在一块儿抠产品是相关的。其实这是唯一重要的……结果很多傻逼企业老板认为自己出去跟别的企业谈合作谈战略布大局才是重要的，这是非常可笑的"[interviews 2014-05-26]；配套证据：开发进度完不成时仍让工程师去调 15 秒动画，工程师"觉得我疯了"。**进度与产品细节冲突时，他选细节。**

**三、危机中的排障方式：清单 + 每日例会 + 亲自下车间。** T1 量产："我们一起开早例会坐下来先报昨天的问题，和新发现的问题是什么，拉总清单一项项对，对完了下车间，一般早例会七点多开"[interviews 2017-04-07]；问题数连涨三周（见案例二）他不改方法、继续每日推进——耐受力极强，也意味着数据恶化本身不会让他中止一条路线。

**四、缺乏合伙人制衡长达四年，且他自己诊断了原因。** 唐岩告诫他"你一定要保证团队里有几个有分量的、真正意义上的合伙人。他们敢跟你拍桌子，而你会重视，会担心……如果他们一拍桌子你就直接让他们滚蛋，那这个团队的天花板也就是你了"；他"因为我认识不深刻，重视不足，锤子科技足足做了四年，才开始有几个重量级的合伙人加入。他们比我的薪资高几倍"[debt_business 2022-06-13]。他接受的制衡形式是**薪资和专业分量都高于自己的人**，不是流程。

**五、可接受的约束形式：事后可编辑，不是事前限制。** 播客制作："整个运作我基本服从指挥。如果现场聊到具体观点有分歧，我也就不管不顾先'愣讲'了。但讲完之后，后期剪辑权在他们手里"[interviews_2025plus 2025-12-08]，他对这种安排的评价见案例一。本维度最有预测力的一条：**给他事前限制会失败，给他事后编辑权会成功。**

**六、判定前提不成立就当天停，并用一句认输句结账。** 现场级：淘宝直播间热水器到手价说不清、僵持不下，当场撤出"算了，你们切回杭州主会场吧，我讲不了了"，只播两个半小时就下播[livestream 2022年12月下旬]。路线级：手机业务——"锤子科技输了就是输了，我们看下一代的战争吧""不改变本质，多活半年或一年而已"[retreat_and_admit 2024-10-31]、"手机时代已经过去了，我们下一代平台上见"[conflict_live 2022-03-17]；被问还敢不敢再做一款手机，直接认怂"因为要烧投资人的钱，所以我确实没这勇气了"[retreat_and_admit 2022-04-16]。**触发止损的不是指标恶化，是他判定这条路的前提已不成立**；判定一旦成立，他自己发起、公开押注过、投入身家的项目也照砍——锤子正是这样的项目，而"几乎从确定锤子科技失败的当天开始，我就在想还完债回来做什么"[debt_business 2022-06-13]。**撤退时不打苦情牌、不做挽救尝试、不留悬念，一句话结束议题并立刻指向下一个战场**，通常同时给出新方向与阶段安排（"先做一些他们不是特别看得上，但价值又足够支撑你往前走的"[interviews_2025plus 2025-12-08]）。与第三条不冲突：战术层的缺陷清单越拉越长他也照推，战略层一旦判定前提失效则当天切换赛道。

**七、事故的补救是超额、限时、带自我归因的。** 玫瑰翻车双倍现金返还（约一百多万），理由"没有什么对消费者的补偿比现金更加诚恳"[livestream 2020-05-20]；自我定位是"我们能做到当出事儿时，是赔付最及时、最爽快最没脾气的"[livestream 2020-12-15]。最完整的执行样本是假洋品牌月饼：当日致歉、"退一赔三的钱款大概会在十个工作日内自动到账"，并当场把原因归给自己这边——"这错误其实还是挺低级的，估计是品控和监督部门，长期没出恶性事故就渐渐懈怠了。从人性的角度，这是不可避免的，还是要靠不断地改进完善流程纪律才行"[retreat_and_admit 2024-09-11]。**他不承诺零缺陷，他承诺赔付速度、给出具体时限、并把责任归到可修的流程上。**

**八、启动速度快、分阶段避锋。** 直播项目从决策到开播约三个月、"启动只用了 2 个月"[speeches 2021-01]；播客第一天就 11 个平台全上[interviews_2025plus 2025-12-08]。AI 创业同样"不敢做巨头们盯着的事"、按阶段避开正面（引文见第六条）[同上]。

## 预测规则

- 要约束他的输出 → 给事后编辑权（剪辑、审稿、代发），不要给事前规则。事前限制会被当场"愣讲"绕过。
- 项目进入攻坚期（战术层：一份具体的缺陷清单） → 每日例会 + 全量清单 + 亲自到一线；指标持续恶化不会让他改路线，只会让他继续推。
- 判定一条业务线的前提不成立（时代过去了 / 要烧别人的钱 / 不改变本质只能多活半年 / 方向本身走不通） → 当天认输并公开宣布，一句话结账、不做挽救、不打苦情牌，同时点出下一个战场与阶段安排。**这是他与"战术层死磕"完全相反的一面，区别只在判定发生在哪一层。**
- 被问一个他公开押注过、说过"押上一切"的项目现在怎么样了 → 不因为宣言在先就维持承诺；如果他已判定方向不成立，会直接说方向错了、停掉相应投入、给出新方向和大致节奏。**"押上一切"约束的是投入强度，不是坚持时长。**
- 进度与产品细节冲突 → 选细节，即使代价是延期。
- 需要他去做找钱、招人、社交型的战略工作 → 完成度低，他会事后如实承认不及格，但不会因此去补这块能力。
- 现场执行失控且无法收拾 → 不硬撑，直接交出控制权并撤离。
- 出现对外事故 → 当天认错、赔付超额、给现金并说出到账时限，归因于自己这边"渐渐懈怠"的流程；同时对造成事故的合作方公开开火。
- 新项目启动 → 数周到两个月内落地，全渠道铺开，先取巨头不感兴趣的位置。
- 团队里出现薪资/专业分量高于他的人 → 会真的忍让并采纳意见；只有流程和制度约束不了他。

## 稳定性分析

中等稳定。战术勤奋这条从未改变；战略缺位这条他修补了一部分——2022 年后主动引入分量足够的合伙人、承认要有 B 计划、承认"不敢再做手机了，怕把别人的钱赔光了"[interviews_2025plus 2025-12-08]。但修补方式仍是**引入外部人替他承担**，而不是自己习得。因此这层的可预测性依赖一个外部变量：他身边此刻有没有他认可分量的合伙人。有，则执行质量显著提升；没有，则退回 2014–2018 年的模式。
